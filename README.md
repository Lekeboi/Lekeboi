## 🚀 Featured project

### [frugal-llm](https://github.com/Lekeboi/Frugal_LLM): what does it really cost to serve your LLM?

A CLI that benchmarks **any OpenAI-compatible endpoint** (tested with vLLM, llama.cpp, Ollama and OpenRouter) and reports:

| Command | What it tells you |
| --- | --- |
| `bench` | Latency percentiles, throughput and **cost per million output tokens** at each concurrency level |
| `quality` / `compare` | How much a **quantised** model's answers drift from full precision, with proper statistics |
| `cost` | The traffic level at which **self-hosting beats a commercial API** |

📊 First study: **Qwen2.5-7B-Instruct in four formats** on affordable rented GPUs, measured against BF16. The dataset is published on [Hugging Face](https://huggingface.co/datasets/Lekeboi/frugal-llm-qwen2.5-7b-quantisation).

```bash
uvx frugal-llm bench --url http://localhost:11434/v1 --model qwen2.5:0.5b
```
